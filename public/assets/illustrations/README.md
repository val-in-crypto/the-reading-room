# Article illustration set

Six original editorial images generated with the built-in image-generation tool using the user's brain-pattern and botanical-collage images as style references.

- `ai-collage.png`: colourful brain pattern on turquoise painted paper.
- `medicine-collage.png`: coral anatomical heart, cells and leaves.
- `nobel-collage.png`: discovery medal, atomic orbit and flowers.
- `tech-collage.png`: vintage blue computer and botanical circuitry.
- `crypto-collage.png`: ochre coins and linked chain loops.
- `imported-collage.png`: an open book with flowers growing from its pages.

Shared art direction: tactile watercolour, translucent torn tissue paper, wrinkled fibres, loose charcoal-black ink contours, coral, ochre, cobalt, turquoise and sage. No typography. Full landscape compositions appear in articles; centred crops appear in the collection thumbnails. Original supplied Figma assets remain available.

The exact generation prompts are recorded in `prompts.json`.
